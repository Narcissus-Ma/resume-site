# 项目描述保留换行设计

## 背景

管理页通过 Ant Design `TextArea` 编辑项目描述，表单、JSON 请求及存储层都会保留字符串中的换行符。简历页目前将描述直接渲染到普通 `<p>` 中；浏览器默认的 `white-space: normal` 会把换行折叠为空格，因此多行内容显示为一段。

## 目标

- 简历页按管理页输入内容保留项目描述中的换行。
- 继续把描述作为纯文本渲染，不解析 HTML，避免引入跨站脚本风险。
- 不改变现有数据结构、接口协议和已保存数据。

## 方案

在 `src/components/experience.tsx` 的项目描述元素上增加 Tailwind `whitespace-pre-line` 类。该规则保留换行符，但仍按普通文本规则折叠连续空格，符合项目描述的输入语义。

不采用 `dangerouslySetInnerHTML` 或富文本编辑器；当前需求仅为保留换行，引入 HTML 存储、清洗和渲染链路会扩大复杂度与安全风险。也不手工按换行符拆分并插入 `<br />`，因为 CSS 已能原生表达相同行为。

## 数据流与兼容性

数据流保持不变：`TextArea` → Ant Design 表单 → JSON API → KV/本地目录 → React 文本节点。只调整最终展示层的空白处理规则。已有单行描述的显示不变；多行描述按原始换行分行；HTML 标签仍作为普通文本显示。

## 测试与验证

- 先增加失败测试，渲染 `Experience` 组件并断言项目描述元素包含保留换行的样式类。
- 修改组件后确认该测试转为通过，并运行完整测试集。
- 运行 ESLint、Prettier 检查和生产构建，确认类型、格式及打包均正常。

## 非目标

- 不支持加粗、列表、链接等富文本格式。
- 不修改工作经历、教育经历和技能描述的展示方式。
- 不迁移或重写历史简历数据。
