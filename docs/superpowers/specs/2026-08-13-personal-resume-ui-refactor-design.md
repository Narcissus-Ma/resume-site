# 个人在线简历 UI 重构设计

## 目标

将现有网站重构为可通过管理页面切换职业方向的个人在线简历：主页提供有辨识度的个人品牌与快速概览，简历详情页提供专业、可打印的完整履历。

## 边界

- 仅修改前端代码及其测试：`src/`、`tests/`、前端构建配置与文档。
- 保持现有路由、API 路径、HTTP 请求方法、返回数据类型与管理页数据编辑能力不变。
- 不修改 `cloudflare/`、Worker、KV、认证逻辑和任何服务端代码。
- 不新增后端字段；页面只消费现有主页、简历和本地回退数据。

## 体验模型

### 主页：个人品牌与摘要

- 首屏按“姓名 → 可配置职业定位 → 简介 → 查看简历”建立视觉优先级。
- 预留可替换头像位；头像未配置或加载失败时使用中性的带姓名首字母占位，不再依赖猫形图像。
- 用单一语义强调色串联字标、头像边框、链接、按钮与时间线，亮暗主题各有对应 token。
- 技能、经历、项目采用不同的阅读节奏：能力摘要以标签/证据呈现，经历为时间线，项目以可访问的案例卡展示；避免重复的满屏区块、居中标题和装饰横线。
- 只有真实 URL 才渲染链接；缺失 URL 的内容以静态信息呈现，不使用 `href="#"`。

### 简历详情页：阅读与打印

- 使用单栏文档式信息架构：个人信息、职业摘要、能力、项目、工作经历、教育、链接。
- 屏幕上保留少量表面层级，打印时移除导航、管理入口、阴影、主题背景和非必要操作。
- 以 `@page`、`break-inside: avoid`、清晰的行距与正文颜色提供 A4 打印稳定性；长条目允许自然分页，不让标题或卡片孤立在页尾。
- 联系方式/所有者信息继续经由现有 PDF 模态框提供，不新增或改动服务端数据。

## 前端架构

- 在 `src/index.css` 集中维护品牌、表面、文本、边框、焦点、间距和打印 token；组件不能继续散落固定 Tailwind 色值。
- 将主页展示组件按职责调整：品牌首屏、能力摘要、履历时间线、项目案例、联系与页脚各自独立。
- 将简历展示组件按文档段落职责调整，并仅从既有 `ResumeData` 读取数据。
- 保持 `useHome`、`useResume`、`publicCatalogApi`、`homeApi`、`resumeApi` 的职责与接口不变；UI 重构不改请求层。

## 无障碍与响应式

- `html` 与 `body` 使用 `overflow-x: clip`，在 320、375、414、768px 不出现横向滚动。
- 交互元素具备 hover、focus-visible、active、disabled 状态；动效只过渡明确属性，并提供 `prefers-reduced-motion` 降级。
- 头像、装饰图形和项目图片都有准确替代文本或明确 `aria-hidden`。
- 标题允许长中英文与职业名称换行；链接与按钮在窄屏不换成两行可点击文本。

## 验收标准

1. 三种语言、明暗主题和两条现有路由均可正常展示，管理页面仍可编辑并刷新内容。
2. 前端请求地址、方法、载荷与现有测试一致；`cloudflare/` 无改动。
3. 所有公开链接均为真实链接或不渲染为链接；页面不存在 `href="#"`。
4. 首页在 320/375/414/768/1280px 无水平溢出，核心简历入口始终可见。
5. 浏览器打印预览为专业 A4 文档，无导航/按钮/深色背景/卡片阴影，条目分页可读。
6. `pnpm test`、`pnpm typecheck`、`pnpm lint` 与 `pnpm format:check` 通过。
